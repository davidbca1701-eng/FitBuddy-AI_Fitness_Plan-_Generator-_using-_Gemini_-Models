# Phase 3: Project Design Phase

This folder contains the design architecture and user interface assets for the FitBuddy application.

### Design Elements Included:
- **System Architecture Diagram:** Outlining the flow between the frontend UI, backend server, and the Gemini API.
- **User Interface (UI) Wireframes:** Initial mockups and visual layouts for the fitness plan generator screens.
- **Workflow Flowchart:** Step-by-step logic detailing how user inputs (goals, diet, fitness level) are processed by the AI to generate custom output.
